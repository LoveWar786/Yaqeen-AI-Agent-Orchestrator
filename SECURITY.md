# Security Policy

We take the security of **Yaqeen** seriously. If you believe you have discovered a vulnerability or security-related issue in this project, please read this document to understand how to report it safely and responsibly.

---

## Supported Versions

Only the current active development and release versions are actively supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub Issues.** 

Instead, report vulnerabilities privately to ensure we can triage, verify, and resolve the issue before details are made public.

### How to Report
1. Contact the maintainers directly on Discord via their DMs:
   - [Heisenberg](https://discord.com/users/916738915262681129) (User ID: `916738915262681129`)
   - [lovewar.](https://discord.com/users/928695371956383824) (User ID: `928695371956383824`)
2. In your report, please include:
   - A detailed description of the vulnerability.
   - The specific component affected (e.g., backend API `/api/search` route, Firestore security rules).
   - Step-by-step instructions to reproduce the issue (including any payload strings or configuration files).
   - The potential impact of the vulnerability if exploited.

### Our Commitment
Once a report is received, the security response team will:
- Acknowledge receipt of your report within **48 hours**.
- Perform a thorough evaluation and coordinate with you on details.
- Work on a patch or mitigation strategy.
- Provide you with periodic updates regarding our remediation progress.
- Give you appropriate credit in our release notes once the patch is public (if desired).

Thank you for helping keep Yaqeen safe and secure for all users and service providers!
